## A little about me

I enjoy taking a real-world frustration and turning it into a focused tool that people can understand, run, and improve.

My work sits where **AI-assisted development**, **workflow automation**, and **practical product design** overlap. That currently means browser extensions, desktop utilities, Power Platform systems, and small experiments that remove friction from everyday work.

I care less about adding complexity and more about shipping software that is useful, legible, and maintainable.

## How I like to build

1. **Start with the actual problem.** Understand the frustration before choosing the technology.
2. **Build the smallest useful system.** Keep the architecture explainable.
3. **Put it in real hands.** Feedback from use beats imagined perfection.
4. **Make the next change easier.** Tests, documentation, and source control are part of the product.

## Let's collaborate

Ideas, bug reports, documentation improvements, and focused pull requests are welcome.

I'm particularly interested in collaborating on:

- browser extensions and integrations for AI-agent workflows;
- small desktop productivity utilities;
- maintainable automation and low-code systems;
- tools that turn complicated operational processes into clear user experiences.

The easiest way to start is through an issue or discussion in the relevant repository.
